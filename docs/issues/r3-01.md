# [R3-01] Реалізувати text/PDF import та synthetic evidence pack

**Відповідальна роль:** R3 — Victoria. GitHub assignee призначає команда.

**Етап:** B. **Залежності для завершення:** [R2-01](r2-01.md)

**Що можна почати раніше:** Synthetic тексти й список metadata можна готувати до schema.

[Інструкція ролі](../roles/r3-evidence.md) · [Спільний контракт](../implementation-contract.md) · [Загальний план](../../team-work-instructions.md)

## Результат

Агенти отримують джерела з точними уривками й metadata без потреби одразу підключати всі external APIs.

## Код і файли

services/api/src/vic/evidence/importer.py; pdf_parser.py; normalization.py; contracts/fixtures/evidence-pack.json

Це очікувані шляхи реалізації; на момент планування код ще не створено. Використовуємо один package `vic`, contracts і LLM adapter R2.

## Що за чим робити

1. Створити synthetic документи підтримки, translation gap і окремий safety update; не використовувати fake реальні DOI.
2. Реалізувати text/JSON importer за contracts v1: sources, evidence, locator, hash, dates, scope.
3. Додати PDF extraction із page locators; scanned/empty PDF повертає пояснену parsing error.
4. Дедуплікувати за hash/stable source ID; user upload позначати user-provided.
5. Передати pack R2 для snapshots і R4/R5 для предметних agents.

## Критерії готовності

- [ ] Кожен evidence посилається на існуючий source; excerpt справді є у document.
- [ ] Synthetic та user-provided provenance збережені.
- [ ] Повторний import не множить однакове evidence як незалежні дослідження.
- [ ] Unreadable PDF не повертає порожній успішний pack.

## Як перевірити

Імпортувати text і текстовий PDF; вручну знайти excerpt на зазначеній сторінці; повторити import; перевірити unreadable document.

## Що передати команді

R2 підключає storage/upload routes; R4/R5 починають agents на одному pack.

У PR: посилання на цю задачу, опис working behavior, commands/input/result перевірки та відомі обмеження. Не закривати live-задачу лише на mock output. API/schema change погодити з R2 і споживачами.
