## Результат

Два agents оцінюють біологічну тезу та missing links до користі для людини, повертаючи перевірні claims.

## Код і файли

services/api/src/vic/agents/science/scientific.py; translation.py; prompts/; відповідні tests

Це очікувані шляхи реалізації; на момент планування код ще не створено. Використовуємо один package `vic`, contracts і LLM adapter R2.

## Що за чим робити

1. Реалізувати analyze_science/analyze_translation через спільний LLM adapter R2.
2. Scientific output розділяє genetics/expression/perturbation/animal/prior programs та correlation/causality.
3. Translation перевіряє molecular effect → exposure → engagement → response → benefit.
4. Повернути RoleResult зі stable claim keys, evidence IDs, support status, risks/unknowns/change conditions.
5. Перевірити scope й contradictory evidence; facts не підставляти з пам’яті моделі.

## Критерії готовності

- [ ] Обидва outputs проходять schema validation.
- [ ] Mouse efficacy не видається за human benefit.
- [ ] Missing safe exposure позначена unknown, а не positive або confirmed negative.
- [ ] Major claims мають evidence або прозору inference/unknown provenance.

## Як перевірити

На synthetic pack без human safety очікувати явну critical unknown; на contradictory pack перевірити відображення негативного evidence.

## Що передати команді

R2 підключає функції; R3 перевіряє claims; R5 отримує предметні risks.

У PR: посилання на цю задачу, опис working behavior, commands/input/result перевірки та відомі обмеження. Не закривати live-задачу лише на mock output. API/schema change погодити з R2 і споживачами.
