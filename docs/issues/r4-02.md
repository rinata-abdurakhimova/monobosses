## Результат

Система пояснює, які дослідження потрібні та який результат має бути досягнутий наступним.

## Код і файли

services/api/src/vic/agents/science/clinical.py; prompts/clinical.md; tests

Це очікувані шляхи реалізації; на момент планування код ще не створено. Використовуємо один package `vic`, contracts і LLM adapter R2.

## Що за чим робити

1. Реалізувати analyze_clinical на science/translation outputs, CaseInput та pack.
2. Вказати population, meaningful outcome, endpoint, comparator, biomarker strategy і study sequence.
3. Для approximate trial size дати assumptions/source або чесний statistical design gap.
4. Перевірити historical analogues/regulatory context; precedent не guarantee.
5. Передати R5 milestone, standard of care/unmet need та risks/questions.
6. Пройти два різні cases одним code path, без hardcoded recommendation за назвою.

## Критерії готовності

- [ ] Clinical plan узгоджений із input stage/modality/scope.
- [ ] Trial size не вигаданий без підстав.
- [ ] Next milestone сформульований і придатний для capital/time scenario.
- [ ] Science/translation gaps збережені у clinical output.

## Як перевірити

На pack із safety gap перевірити plan limitations; на другому case endpoints/population змінюються відповідно до evidence.

## Що передати команді

R5-02 використовує plan/milestone; R2 додає clinical stage; R3 перевіряє claims.

У PR: посилання на цю задачу, опис working behavior, commands/input/result перевірки та відомі обмеження. Не закривати live-задачу лише на mock output. API/schema change погодити з R2 і споживачами.
