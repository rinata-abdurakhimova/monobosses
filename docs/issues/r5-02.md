## Що за чим робити

1. analyze_investment читає clinical/market outputs через pipeline.
2. Показати capital/time, value inflection points, future financing, licensing/acquisition/development outcomes.
3. Дати assumptions, units/currency/date/geography; company cash не прирівнювати до program budget.
4. Реалізувати scenarios на Python-функціях; якщо inputs відсутні — gap та evidence needed.
5. Відділити diligence costs від development capital; додати decision-changing financial questions.

## Критерії готовності

- [ ] Усі required financial outputs присутні або обмеження пояснені.
- [ ] Розрахунки відтворюються за переліченими inputs.
- [ ] Немає вигаданих суттєвих numeric inputs.
- [ ] Missing/zero values і unit consistency перевірені.

## Як перевірити

Synthetic known inputs дають незалежно перевірений результат; missing budget не перетворюється на точну цифру.
